# 中文翻译校订记录

校订对象：`redpoint-rope-soloing-revised-2023.zh.md`。逐段对照同目录英文稿；正文保留作者 2023 年的第一人称立场。此次工作是翻译校订，不是对系统安全性的认证。

| 原文术语／表达 | 原译问题 | 校订处理 |
| --- | --- | --- |
| water knot | 误译为平结，指向了另一种绳结 | 水结（扁带结） |
| bight | 误译为一股绳，改变打结说明 | 对折绳弯，区别于 strand（绳股） |
| Progress Capturing Pulley | “进度捕获滑轮”不符合器械语境 | 止回滑轮（PCP）；Petzl 中文称单向制停滑轮 |
| structural gear loop | “结构性”未明确备份承重用途 | 承重装备环，区别于普通装备环 |
| full strength / fully rated | “全力”“全强度”含糊 | 按语境译为完整承重能力／额定承重能力 |
| carabiner / locking carabiner | 普通锁扣与带锁锁扣混用，locking 被一律译成丝扣 | 普通锁扣／带锁锁扣；不把自动锁闭锁扣写成丝扣 |
| captive / cross-loading | “防脱”未表达定位功能；“爆开”不精确 | 定位隔挡／横向受力／断裂 |
| seat-belt style | “安全带式”容易被理解为攀登安全带 | 类似汽车安全带的制动系统 |
| aid ladder clipping sequence | 前后保护点关系含糊 | 站上下一个点的绳梯后，再将先锋绳扣入前一个点 |
| backfeed | 需要明确绳索运动方向及隐藏松弛 | 保留“回喂”，说明保护侧绳重抽绳并在底部积累松弛 |
| soft / hard refixing | 固定方向与有效动力绳长度不清 | 软式／硬式再固定，明确收紧方向及坠落系数风险 |
| tram | 简化为荡回岩壁，遗漏沿绳导向 | 沿保护侧绳股导向回壁，保留英文 |
| biner block | “主锁结”混淆绳结与阻挡系统 | 锁扣阻挡系统 |
| short-fixing | “短距离固定绳”未保留技术名称 | 短固定（short-fixing） |
| Plush / spring rate / 1:1 elongation | 豪华／强度／1:1 的意思不准确或不清 | 柔软版／刚度／至少 100% 伸长 |

关键英制尺寸补充了近似公制值；攀登难度补全了 YDS 的 5. 前缀。21 张图片的顺序、路径和所有原有链接目标均已检查保留。

## 原文自身的技术限制

以下问题属于原文主张，不能通过润色变成已验证结论：

- Petzl 不允许 GRIGRI、GRIGRI+、NEOX 用于自我保护；常规保护要求始终握持制动侧绳索。见 [厂家技术说明](https://www.petzl.com/US/en/Sport/Self-belaying-is-not-authorized-for-GRIGRI--GRIGRI-Plus-and-NEOX)。中文已在文首加入独立译者说明。
- 原文所述 GRIGRI+ 的动力绳适配范围为 8.5–11 mm 单绳，最佳范围为 8.9–10.5 mm。原文的 8.2 mm 半绳用法超出该范围；TR 模式不改变适配范围。见 [厂家使用说明书](https://www.petzl.com/sfc/servlet.shepherd/version/download/068Tx000009Y8pMIAS)。中文绳径章节已补充独立译注。
- 活结约 4 kN 的数据是原文引用的特定测试，不是通用额定值；普通装备环上的阻挡结不等于独立承重备份。正文保留原文的区别与局限。
- 作者对器械改装、Silent Partner 内部磨损和自制弹力锚站的描述属于其个人经验或解释。原文称附录未讨论安全及架设理论，因此不能视为完整架设规范。
- 原稿的单结、HUUD 悬挂点和自制弹力装置连接细节依赖配图；校订没有用文字擅自补全原文未明确的结构。具体产品版本及实物连接仍须对应原始图示核对。

术语参考：[Petzl MICRO TRAXION 中文产品说明](https://petzl.cn/sport/滑轮/MICRO-TRAXION)。
